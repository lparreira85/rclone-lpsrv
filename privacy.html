Privacy policy - rclone-lpsrv

Last updated: 21 October 2026

rclone-lpsrv is a personal tool. It is used only by its owner, to back up the owner's own files to the owner's own Google Drive.

  • What it accesses: only files and folders that the tool itself creates in the owner's Google Drive (Google permission drive.file). It cannot see any other file in the Drive.
  • What it collects: nothing. No personal data is collected, stored by the developer, sold, shared or used for advertising.
  • Where data goes: directly from the owner's server to the owner's Google Drive. The files are encrypted before upload. There is no third-party server in between.
  • Access tokens: stored only on the owner's server, readable only by the owner. Access can be revoked at any time at myaccount.google.com/permissions.

Política de privacidade

O rclone-lpsrv é uma ferramenta pessoal, usada apenas pelo seu dono para copiar os seus próprios ficheiros para o seu próprio Google Drive. Só acede aos ficheiros que a própria ferramenta cria (permissão drive.file), não recolhe dados pessoais, não os partilha nem os vende, e os ficheiros seguem cifrados diretamente do servidor do dono para o Drive do dono. Os tokens de acesso ficam apenas no servidor do dono e podem ser revogados a qualquer momento em myaccount.google.com/permissions.
